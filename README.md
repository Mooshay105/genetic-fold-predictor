# Genetic Fold Predictor

This site started as a school project for my 56DIGI class at Ao Tawhiti
as a simple "Pick The AI Image" site, but I was told that it needed to
be useful in the real world, so I pivoted to this: a website that
predicts how proteins fold. Then I got so proud of what I had made, I
wanted to publish it.

**Live site:** [genetic-fold-predictor.malcolmjh.com](https://genetic-fold-predictor.malcolmjh.com)

## Tech Stack

- **Framework:** Next.js
- **Styling:** Tailwind CSS
- **Protein Folding:** ESMFold (via NVIDIA Cloud / NIM API)
